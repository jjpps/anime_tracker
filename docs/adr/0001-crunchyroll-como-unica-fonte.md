# Crunchyroll como única fonte; sai o match com AniList/MAL

O objetivo é mostrar o que já está disponível para assistir na Crunchyroll, e o catálogo da própria CR responde isso sozinho (temporadas de cada anime + meu histórico). O match temporada → obra no AniList/MAL (clientes, catálogo local, fila de revisão, tela de correções) foi removido porque não alimenta nada desse objetivo e era a maior parte do código. Se um dia quisermos "anunciado/em breve" (sequência ainda fora da CR), a volta começa pelo git, não por esse código mantido parado.
